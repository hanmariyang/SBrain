## 1. Goal

SBrain의 BI(네이비/골드)를 기반으로 라이트 모드 디자인 시스템을 구축하고, 레이아웃·Brain Map·전체 UI를 리뉴얼한다.

**성공 기준:**
1. 모든 화면이 통일된 디자인 토큰(컬러, 폰트, 간격)을 사용
2. 2단 사이드바 레이아웃 적용
3. Brain Map이 위계 구조 + 파일타입별 노드 + DB 연결선을 표현
4. 모바일(iOS) 전환 시 동일 디자인 토큰 재사용 가능

## 2. Scope

### In Scope
- 디자인 시스템 (컬러 팔레트, 타이포그래피, 간격, 그림자, 라운딩)
- 레이아웃 재설계 (2단 사이드바, 탑바, 콘텐츠, 하단 패널)
- Brain Map 리뉴얼 (라이트 배경, 위계, 노드 분화, DB 연결)
- 전체 뷰 리스타일링 (List, Detail, DB Browser, Terminal, 검색)
- 앱 아이콘 적용 (로고 확정 후)
- logo03 디자인 방향서 작성

### Out of Scope
- 모바일(iOS) 앱 개발 (디자인 토큰만 준비)
- 백엔드 변경
- 신규 기능 추가 (UI만 변경)

## 4. Layout Design

### 4.1 전체 레이아웃 — 2단 사이드바

```
┌──────┬────────────┬─────────────────────────────────┐
│ Icon │  Explorer  │                                 │
│ Bar  │   Panel    │        Main Content             │
│      │            │   (List / Brain Map / DB)       │
│ 48px │  240px     │                                 │
│      │ (접기가능)  │                                 │
│      │            │─────────────────────────────────│
│      │            │   Terminal Panel (토글)          │
│ ──── │            │                                 │
│ 설정  │            │                                 │
└──────┴────────────┴─────────────────────────────────┘
```

**아이콘 바 (좌측 48px, 항상 고정)**

| 위치 | 아이콘 | 기능 |
|------|--------|------|
| 상단 | SB 로고 (소형) | 홈 / 전체 보기 |
| | 내 기억 아이콘 | 개인 워크스페이스 전환 |
| | 프로젝트 1~N | 각 프로젝트 이니셜/색상 원형 |
| | + 버튼 | 프로젝트 추가 |
| 중간 | 구분선 | — |
| | 검색 | 회상(Recall) 패널 열기 |
| 하단 | List 뷰 | 뷰 모드 전환 |
| | Brain Map | 뷰 모드 전환 |
| | DB Browser | 뷰 모드 전환 |
| | 터미널 | 하단 터미널 토글 |
| 최하단 | 설정 | 앱 설정 |

**탐색 패널 (240px, 접기 가능)**

- 선택된 프로젝트의 파일 트리
- 검색 선택 시: 검색 결과 목록
- 접으면 아이콘 바만 남아 콘텐츠 영역 최대화

**메인 콘텐츠 (나머지 영역)**

- 뷰 모드에 따라 내용 변경 (List, Brain Map, DB)
- 우측 디테일 패널 제거 → 메인 콘텐츠 내에서 처리
  - List 뷰: 선택한 파일 내용을 메인 영역에 표시
  - Brain Map: 전체 영역 사용
  - DB: 테이블 목록 + 데이터 뷰

**하단 터미널 패널 (토글)**

- 아이콘 바의 터미널 버튼으로 토글
- 라이트 모드 터미널 (크림 배경 + 네이비 텍스트)

### 4.2 탑바 간소화

기존 탑바의 뷰 모드 토글, 프로젝트 정보 등이 사이드바로 이동하면서 탑바가 간소화됨:

```
┌────────────────────────────────────────────────┐
│  SBrain           [검색바]           [상태표시]  │
└────────────────────────────────────────────────┘
```

- 좌: 현재 프로젝트명 / 경로 (breadcrumb)
- 중앙: 검색 바 (회상하기)
- 우: 백엔드 상태, 인덱싱 진행률

## 5. Brain Map Renewal

### 5.1 라이트 배경

- 배경: `bg.primary` (#FAF8F5)
- 노드: 네이비 계열
- 연결선: 골드/네이비 반투명
- 선택 노드: 골드 하이라이트

### 5.2 노드 분화 (파일타입 + 크기)

| 파일 타입 | 노드 형태 | 색상 |
|-----------|-----------|------|
| Markdown (.md) | 원형 | `navy.700` |
| HTML (.html) | 육각형 | `accent.blue` |
| DB 테이블 | 사각형 (라운드) | `accent.green` |
| 폴더 (그룹 노드) | 큰 반투명 원 | `navy.100` |

**노드 크기**: 파일 내 뉴런(청크) 수에 비례

### 5.3 위계 구조 (Hierarchy)

**폴더 기반 그룹핑:**
```
프로젝트 루트 (가장 큰 영역)
├── 폴더 A (그룹 노드, 반투명 영역)
│   ├── file1.md (노드)
│   ├── file2.md (노드)
│   └── subfolder/ (더 작은 그룹)
│       └── file3.md (노드)
└── 폴더 B (그룹 노드)
    └── file4.html (노드)
```

- 폴더를 반투명 원/영역으로 표현, 그 안에 파일 노드 배치
- 폴더 깊이에 따라 영역 크기 계층화
- 줌인하면 하위 구조가 점점 보임 (Semantic Zoom)

### 5.4 연결선 (Synapse) 유형

| 연결 유형 | 선 스타일 | 색상 |
|-----------|-----------|------|
| 임베딩 유사도 | 곡선, 반투명 | `gold.400` 20% |
| 같은 폴더 | 직선, 가는 | `navy.100` |
| DB 참조 | 점선, 아이콘 | `accent.green` |

### 5.5 DB 테이블 연결

- 문서 내용에서 DB 테이블명이 감지되면 (백엔드에서 매칭)
- 해당 문서 노드 ↔ DB 테이블 노드 사이에 점선 연결
- DB 테이블 노드는 별도 영역에 배치 (Brain Map 우측 또는 하단)

### 5.6 인터랙션 개선

| 동작 | 현재 | 리뉴얼 |
|------|------|--------|
| 호버 | 없음 | 노드 확대 + 파일명 툴팁 + 연결선 하이라이트 |
| 클릭 | 선택 | 선택 + 연결된 노드 강조 + 나머지 페이드 |
| 더블클릭 | 없음 | 해당 파일을 메인 콘텐츠에서 열기 |
| 드래그 | 회전 | 회전 유지 |
| 스크롤 | 줌 | 줌 + Semantic Zoom (줌인 시 폴더 내부 보임) |
| 우클릭 | 없음 | 컨텍스트 메뉴 (열기, Brain에서 제거, DB 연결 보기) |
| 필터 | 프로젝트 탭 | 사이드바에서 프로젝트/폴더 선택 시 자동 필터 |

- 라운드 사각형(squircle) 마스크 대응 — macOS 앱 아이콘 형태

**참고 키워드 (이미지 생성 도구용)**:

Flat minimal app icon, "SB" monogram, neural network nodes connected
