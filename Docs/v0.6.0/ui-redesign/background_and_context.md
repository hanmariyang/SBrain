## 1. Background Summary

- SBrain v0.5.0까지 기능 중심 MVP로 개발, UI/UX 디자인은 최소한으로 진행
- 다크 모드 기반의 칙칙한 색상, 시스템 기본 폰트, 여백 부족 등 디자인 품질 낮음
- 로고/BI가 확정되면서 이에 맞는 통합 디자인 시스템 구축 필요
- 향후 모바일(iOS) 버전 계획이 있어 크로스 플랫폼 대응 가능한 디자인 시스템 필요

## 2. Problem Definition

- **대상**: SBrain 사용자 (본인 + 향후 외부 배포)
- **현재 문제점**:
  - 색상: 다크 모드 일변도, 보라/시안 조합이 칙칙하고 BI와 무관
  - 폰트: 시스템 기본 사용, 크기/무게 체계 없음
  - 레이아웃: MVP급 배치, 여백 부족, 시각적 위계 부재
  - 아이콘: 앱 아이콘 없음, SF Symbols만 사용
  - Brain Map: 다크 배경 고정, 노드가 단순 원형, 위계/구조 표현 없음
  - 터미널: 다크 배경 고정
  - 모바일 대응: 고려 없는 데스크탑 전용 레이아웃

## 3. Root Cause Hypothesis

1. BI(Brand Identity) 없이 개발 시작 → 색상/폰트 임의 선택
2. 디자인 시스템(토큰, 컴포넌트) 부재 → 화면마다 스타일 파편화
3. 기능 우선 개발 → 레이아웃/여백/인터랙션 후순위

## 4. Risk If Not Addressed

- 외부 배포 시 첫인상이 "미완성 앱"으로 인식
- 모바일 버전 개발 시 디자인 시스템 부재로 이중 작업
- 사용자 경험 저하로 기능이 좋아도 이탈

## 5. Target Outcome

- BI 기반 통합 디자인 시스템 (컬러, 타이포, 간격, 컴포넌트)
- 라이트 모드 기본, 따뜻한 크림/아이보리 + 네이비/골드 포인트
- 2단 사이드바 레이아웃 (아이콘 바 + 확장 패널)
- Brain Map 완전 리뉴얼 (라이트 배경, 위계 표현, 파일타입별 노드, DB 연결)
- 모바일 전환을 고려한 반응형 구조
