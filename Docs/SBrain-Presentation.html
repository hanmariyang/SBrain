01
Problem

지식은 쌓이지만, 연결되지 않는다

수백 개의 메모, 문서, 기록들 —
필요한 정보를 찾는 데 걸리는 시간은 점점 늘어갑니다.
📂
파일이 묻힌다
폴더 깊숙이 저장한 문서는 다시 찾기 어렵고, 키워드 검색으로는 원하는 맥락을 놓칩니다.
🔗
연결이 끊어진다
서로 관련 있는 메모들 사이의 연결고리를 사람이 일일이 기억해야 합니다.
📱
이동 중 접근 불가
맥북에 저장한 자료를 이동 중에 확인할 방법이 없습니다.
02
Solution

뇌의 방식으로 지식을 관리하다

노트를 뉴런으로, 유사한 내용의 연결을 시냅스로 표현하여
실제 뇌 속을 탐색하는 듯한 경험을 제공합니다.
기존 방식SBrain의미
파일, 메모Memory (기억)하나의 문서
문단, 핵심 내용Neuron (뉴런)의미 단위로 분리된 지식 조각
관련 문서Synapse (시냅스)자동 발견된 연결 관계
폴더 정리Memorize (기억하기)폴더 선택만으로 자동 분석
검색Recall (회상)의미 기반으로 관련 기억 회상
03
Core Feature

3D Brain Map

모든 노트가 3D 공간에 뉴런으로 배치됩니다.
비슷한 내용끼리 시냅스로 자동 연결되어 지식의 구조가 한눈에 보입니다.
🌐
3D 시각화
뉴런이 구체 위에 분포하여 전체 지식 구조를 입체적으로 탐색할 수 있습니다.
🔄
직관적 조작
드래그로 회전, 스크롤로 줌, 클릭으로 노트 선택. 터치 기기에서는 핀치/스와이프.
✨
자동 연결 발견
AI가 내용의 의미를 분석하여 관련 노트를 자동으로 시냅스 연결합니다.

04
Smart Search

회상 (Recall)

키워드가 아닌 의미로 검색합니다.
"지난 회의에서 논의한 인증 방식"처럼 자연스럽게 질문하면, 관련된 기억을 회상합니다.
🔍
의미 기반 검색
정확한 단어를 기억하지 못해도 괜찮습니다. 내용의 맥락과 의미를 파악하여 가장 관련 높은 노트를 찾아줍니다.
🧠
Brain Map 연동
검색 결과가 Brain Map에서 하이라이트됩니다. 관련 뉴런 주변의 연결 관계까지 한눈에 파악할 수 있습니다.

06
Integrations

업무 도구와 연결

노트뿐만 아니라 Slack 대화와 Google Calendar 일정도
하나의 워크스페이스에서 함께 관리합니다.
💬
Slack 연동
Slack 채널의 대화를 불러오고, 앱 안에서 바로 답장할 수 있습니다. 중요한 논의를 놓치지 마세요.
📅
Google Calendar
일정을 확인하고 새 이벤트를 만들 수 있습니다. 노트를 보면서 미팅 일정을 바로 체크하세요.
🗄️
데이터베이스 탐색
PostgreSQL에 연결하여 테이블, 데이터를 앱 안에서 직접 탐색합니다. 별도 DB 도구가 필요 없습니다.
07
Features

주요 기능 한눈에

🧠
3D Brain Map
모든 노트를 3D 뉴런으로 시각화. 자동 회전, 드래그 조작, 뉴런 선택으로 문서 열람
🔍
의미 검색 (Recall)
AI가 내용의 의미를 분석하여 자연어 질문으로 관련 노트를 찾아줍니다
☁️
클라우드 동기화
파일 변경 시 자동으로 클라우드에 반영. 맥이 꺼져 있어도 아이폰에서 열람 가능
📱
iPhone 앱
이동 중에도 3D Brain Map 탐색, 노트 열람, 검색. 터치 제스처 최적화
📂
멀티 프로젝트
여러 폴더를 동시에 열어 하나의 Brain Map에서 통합 탐색. 프로젝트별 필터링
💬
Slack & Calendar
Slack 대화와 Google Calendar 일정을 노트와 함께 한 화면에서 관리
🖥️
내장 터미널
앱 안에서 터미널을 열어 바로 작업. 하단 패널 또는 전체 화면 모드 지원
🔄
자동 업데이트
새 버전이 나오면 자동으로 업데이트. 항상 최신 기능을 사용할 수 있습니다
