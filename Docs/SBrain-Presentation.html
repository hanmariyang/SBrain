01
Problem

지식은 쌓이지만, 연결되지 않는다

수백 개의 마크다운 파일, 수십 개의 데이터베이스 테이블 —
필요한 정보를 찾는 데 걸리는 시간은 점점 늘어갑니다.
📂
파일이 묻힌다
폴더 깊숙이 저장한 문서는 다시 찾기 어렵고, 키워드 기반 검색은 맥락을 무시합니다.
🔗
연결이 끊어진다
관련 있는 노트와 DB 테이블 사이의 연관성을 사람이 일일이 기억해야 합니다.
🐘
DB 조회 비용
원격 PostgreSQL에 반복 쿼리하면 서버 부하가 증가하고 응답이 느려집니다.
02
Concept

뇌의 메타포로 설계하다

노트를 뉴런으로, 유사성을 시냅스로 표현하여
실제 뇌 속을 탐색하는 듯한 경험을 제공합니다.
일반 용어SBrain 용어설명
노트 / 파일 Memory 기억 하나의 마크다운 파일 또는 DB 테이블
청크 / 레코드 Neuron 뉴런 텍스트 조각 + 벡터 임베딩
유사 연결 Synapse 시냅스 임베딩 코사인 유사도 기반 연결선
인덱싱 Memorize 기억하기 폴더 스캔 → 벡터 임베딩 저장
검색 Recall 회상 자연어 질의 → 유사 기억 회상

08
Key Features

핵심 기능

🧠
3D Brain Map
PCA 기반 3D 뉴런 배치, 코사인 유사도 시냅스 곡선, 자동 회전 + 인터랙티브 카메라
🔍
벡터 검색 (Recall)
자연어 질의로 의미적으로 유사한 기억을 회상. Brain Map에서 매칭 뉴런 하이라이트
🗄️
PostgreSQL 브라우저
스키마/테이블/컬럼/행 탐색, 검색, 페이지네이션. 로컬 미러링 지원
📊
DB ↔ 파일 통합 뷰
파일 뉴런과 DB 뉴런이 같은 Brain Map에 공존. 스키마별 별도 구체로 시각화
🐳
Docker 원커맨드 셋업
make up 하나로 PostgreSQL + Django 백엔드 실행
✋
핸드 트래킹 (실험적)
손 제스처로 Brain Map 탐색 — 포인팅, 핀치 회전, 빅토리 스크롤
